# 수궁야행 · 현장 수정본

Vite + React + MediaPipe 기반 1인 관객 인터랙티브 미디어아트입니다.
QR 즉시 입장 및 Supabase 연결을 위한 최초 설정은 [APP-INTEGRATION.md](APP-INTEGRATION.md)를 먼저 확인하세요. 빈 부스에서 QR을 인증하면 아래 기존 작품 흐름이 활성화됩니다. 체험 중에는 다른 관객의 입장을 거절하며 대기자 명단을 만들지 않습니다.
이 버전은 00~09 전체 흐름과 4K 원본 영상 5개를 포함합니다. 전시 PC에서 로컬 서버로 실행합니다.

## 담당자 실행 방법 (Windows)

1. Node.js 24 LTS를 https://nodejs.org/ 에서 설치합니다.
2. 이 브랜치 전체를 내려받아 ZIP을 풀거나 Git으로 복제합니다.
3. 프로젝트 폴더의 **설치.cmd**를 한 번 실행합니다. 인터넷 연결이 필요하며 의존성 설치와 빌드를 수행합니다.
4. **실행.cmd**를 실행하고 창을 열린 상태로 둡니다.
5. Chrome 또는 Edge에서 **http://127.0.0.1:4173/** 를 엽니다.
6. **웹캠 인식 켜기**를 누르고 카메라 권한을 허용합니다. 사용자 클릭 후 영상·음악 재생이 준비됩니다.
7. Windows 디스플레이 설정에서 TV/모니터 해상도를 **3840×2160**으로 설정하고, 앱의 운영 메뉴에서 전체 화면을 선택합니다.

Git으로 받을 때:

```powershell
git clone --branch 1조 --single-branch https://github.com/NamMoMo/sugung.git
cd sugung
npm ci
npm run build
npm run preview -- --port 4173 --strictPort
```

macOS에서 실행할 때도 위 npm 명령을 사용하고, 브라우저에서 같은 주소를 엽니다.
수정 후에는 `npm run build`를 다시 실행해야 전시 실행본에 반영됩니다.
`index.html` 파일을 더블클릭하여 여는 방식 대신 위 로컬 서버 주소를 사용하세요.

## 4K 영상

아래 파일은 모두 **3840×2160, 24fps** 원본입니다. `public/videos` 경로와 파일명을 유지하세요.

- opening_VD.mp4: 16.9초
- deepsea_VD.mp4: 약 19.96초, 장면에서 0.8배속
- king_VD.mp4: 14.75초
- rabbit_VD.mp4: 16초
- ending_VD.mp4: 원본 전체 14초

화면 설계와 출력 캔버스도 3840×2160입니다. 4K TV 연결에는 4K 출력이 가능한 PC/GPU와 케이블이 필요합니다.
웹캠 입력은 1080p를 요청하며, 4K 출력 영상과 웹캠 입력 해상도는 별개입니다.
버전·영상 SHA256 확인은 `release.json`을 참고하세요.
`ending_VD-edited.mp4`와 `ending_VD-trimmed.mp4`는 이전 편집 기록이며, 현재 재생에는 사용하지 않습니다.

## 장면 순서

00. 대기화면 → 01. 오프닝 → 02. 자라미니게임 → 03. 용왕 → 04. 4분할글리치 → 05. 토끼해킹 → 5.5 메인시작 → 06. 메인콘텐츠 → 07. 최종결과 → 7.5. 엔딩전 → 08. 엔딩 → 09. 마지막.

- 관리자 **0**: 다음 장면으로 이동. 09에서는 00으로 복귀하며 체험 초기화.
- 관리자 **1**: 어느 장면에서나 00으로 초기화.
- 키워드 입력창/한글 조합 중에는 0·1 단축키가 동작하지 않습니다.
- 5.5/06/07의 English 버튼: 클릭 또는 주먹 3초로 언어 전환. 관객이 직접 입력한 키워드는 원문 유지.
- 06: 주먹 2초로 잡기 → 몸 밖에서 손 펴서 버리기, 몸 안에서 놓으면 복귀. 키보드 Enter로 추가. 합산 7회 완료.
- 08: 기본 2~3초 반복 → 첫/둘째 타격 각각 4~5초 1회 후 6~7초 반복 → 셋째 타격 7~14초. 종료 후 되감기 없이 흰 화면 2초 → 09. BGM은 종료 시점부터 3초 동안 감쇠.

## 현장 점검

- 관객과 웹캠 간격은 약 1.5~2m를 기준으로 조정하고 머리/어깨/양팔이 프레임에 들어오게 합니다.
- TV 소리 출력 장치와 Windows/브라우저 볼륨을 확인합니다.
- 전체 장면·양손 인식·키워드 추가/버리기·엔딩 3회 타격·09의 0번 복귀를 실제 전시 PC에서 한 번 완주합니다.
- 카메라를 사용하는 다른 앱은 종료합니다. 카메라 권한 차단 시 브라우저 사이트 설정에서 허용합니다.
- MediaPipe 모델과 WASM은 `public/mediapipe`에 포함되어 있습니다. 기본 폰트는 Google Fonts를 요청하며, 인터넷이 없으면 시스템 폰트로 표시됩니다.
- 로컬 4K 파일 포함 여부와 실제 출력 성능은 별개이므로, 전시 PC에서 영상 재생과 인식을 함께 점검하세요.
