1. 실행
ZIP을 모두 압축 해제한 다음 「실행하기.bat」를 더블클릭하세요.
자동으로 열린 Edge 또는 Chrome에서 「카메라 연결 후 시작하기」를 누르고 카메라를 허용하세요.
카메라 없이 확인하려면 「마우스로 미리 체험하기」를 누르세요.
서버 창은 작품을 사용하는 동안 닫지 마세요. 종료할 때 Ctrl+C를 누르세요.
실행에는 Python 3와 Edge 또는 Chrome이 필요합니다. 카메라 모델과 효과음은 폴더에 포함되어 실행 중 인터넷 연결은 필요 없습니다.
폴더를 다른 컴퓨터로 옮길 때는 일부 파일만 옮기지 말고 폴더 전체를 복사하세요.

2. 최종 재생 순서
시작영상 1080 → 인터랙티브 1(7문항 버블 선택) → 깊은 수중 하강 → 인터랙티브 2(단어 잡기) → 빛 모으기 → 마음의 기울기(좌우 결과) → 빛의 길 → 수정 엔딩과 효과음

3. 조작
인터랙티브 1: 손끝 또는 마우스를 버블에 1초간 머무르게 합니다.
인터랙티브 2: 단어 위에서 주먹을 쥐거나 양손으로 박수칩니다. 마우스에서는 클릭합니다.
카메라에서 손이 보이지 않으면 단어 낙하와 체험 시간이 잠시 멈춥니다.
단어를 15회 잡거나 손이 보이는 누적 체험 시간이 60초가 되면 결과로 넘어갑니다.

4. 점수와 방향
왼쪽: 발전하고자 하는 삶 / 오른쪽: 안정적인 삶
인터랙티브 1 선택 1회 = 1점, 인터랙티브 2 단어 잡기 1회 = 1점. 최대 22점.
점수가 높은 쪽의 AI 영상을 재생합니다. 동점이면 마지막으로 잡은 단어, 없으면 마지막 질문의 선택을 따릅니다.
단어 28개의 분류는 작품 설정의 「단어 분류·점수 기준 보기」 또는 scores.html에서 확인하세요.

5. 소리와 전시 운영
처음 시작 버튼을 누르면 오디오가 활성화됩니다.
오른쪽 아래 설정 또는 D 키에서 전체 음량·음소거·입력 방식·카메라 미리보기를 조절합니다.
1: 처음으로 / 2: 버블 질문 / 3: 단어 비 / 4: 왼쪽 발전 미리보기 / 5: 오른쪽 안정 미리보기
엔딩에는 효과음이 이미 포함되어 있습니다. 원래 소리에 직접 합성한 효과음을 더했습니다.
기본 음량은 65%입니다. 전시 스피커에 맞춰 설정에서 조절하세요.
실제 전시 전에 카메라 거리·조명·스피커 음량을 한 번 확인하세요.
