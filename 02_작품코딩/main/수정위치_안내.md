현재 운영 중인 본 사이트의 전체 소스입니다. 이 폴더 내용이 지금(2026-10-17) 배포된 버전과 같습니다.
시연용 사이트는 이 폴더를 고친 뒤 상위 폴더의 `make-demo.mjs` 로 만듭니다 (상위 `README.md` 참고).

## 글꼴과 색

- 글꼴: **고운바탕 (Gowun Batang)** — 제목·대사·자막·꼬리표·마무리 판 등 대부분의 글씨. **IBM Plex Sans KR** — 작은 안내 글씨·직원 화면. 둘 다 Google Fonts 에서 불러옵니다 (`index.html` 위쪽의 `fonts.googleapis.com` 줄).
- 빔 화면은 처음 열면 초롱 없이 빈 하늘로 시작하고, 연 뒤에 들어온 기록만 띄웁니다. 행사 중에는 새로고침하지 마세요.
- 금빛 자개 색 묶음: `#E8C98A #FFF4DA #D9AE68 #F6DCC6 #FFFBEF #E2BC7C #F3D6B8 #FFF6E2` (꼬리표·제목·테두리에 공통으로 씀). 단색이 필요할 때는 `#EBCB8E`.
- **금빛 선·테두리·제목 색을 CSS 그라데이션으로 바꾸지 마세요.** 삼성 인터넷·안드로이드 크롬의 '다크 모드 강제 변환'이 켜진 휴대폰에서는 CSS 로 칠한 밝은 금색이 어두운 붉은 갈색으로 바뀝니다. 그래서 이 부분들은 canvas 로 그립니다 (`paintGold`, `paintEndFrame`, `paintTitle`, `paintNeon`).

## 고친 뒤 확인하기

1. 컴퓨터에서 이 폴더를 열고 터미널에서 `npx serve .` (또는 `npx wrangler pages dev .`) 를 실행합니다.
2. 브라우저에서 `http://localhost:3000/?id=0417` 로 열어 확인합니다. 파일을 더블클릭해서 열면 동작하지 않습니다.
   - 서버 기능(직원 화면 저장, 빔 화면 연결)까지 보려면 `npx wrangler pages dev . --kv ROOMB` 로 실행하세요.

## 배포하기

Node.js(LTS)가 설치된 컴퓨터에서, 이 폴더에서 터미널을 열고:

```
node setup.mjs --deploy
```

처음이면 브라우저가 열려 Cloudflare 로그인을 묻습니다. 프로젝트 소유자(Cloudflare 계정)의 로그인 또는 그 계정에서 만든 API 토큰이 필요하니, 배포 권한은 담당자에게 받아 주세요.
배포 후 1분 안에 https://sugung-roomb.pages.dev 에 반영되며, 휴대폰에서는 한 번 새로고침해야 보일 수 있습니다.

## 주의

- A방 QR은 꼭 `?id=번호` 형식이어야 결과가 서버에 저장되고 빔 화면에 초롱이 뜹니다. `&items=` 나 `&k=` 가 붙은 주소는 저장되지 않습니다.
- `vendor/`, `_worker.js`, `_routes.json`, `wrangler.toml` 은 필요할 때만 수정하세요. 서버를 고치면 직원 화면·빔 화면이 함께 영향을 받습니다.
- 여러 사람이 동시에 고치면 나중에 배포한 쪽이 덮어씁니다. 배포 전에 서로 알려 주세요.
- 본 사이트를 고쳐 올렸다면 시연용 사이트도 `make-demo.mjs` 로 다시 만들어 올려야 같은 모습이 됩니다.
