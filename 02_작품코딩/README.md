# 4조 청사초롱, 꿈을 담다 · 실행 안내

수궁야행 방 B 작품의 전체 소스입니다. 이 폴더는 2026-10-20 현재 운영 중인 사이트(https://sugung-roomb.pages.dev)와 같은 내용입니다.

## 1. 담당자와 현재 상태

- 팀 / 작품명: 4조 / 청사초롱, 꿈을 담다 (방 B)
- 참여자 / 담당 역할: 박서영 (메인 프론트엔드 디자이너), 이연우 (현장 운영 시험, 서브 디자이너), 배준섭 (기획, 스토리·CDDQ 연결)
- 문의 담당자 / 연락 방법: 박서영 / 010-9705-1779
- 작성일: 2026-10-20
- 현재 가능한 체험:
  - 휴대폰에서 초롱 색 고르기
  - 꼬리표 떼기와 되돌리기, 마지막 하나 남기기
  - 닉네임 정하기, 위로 밀어 초롱 날리기, 내 초롱 이미지 저장
  - 빔 화면에 초롱이 떠오르는 장면
  - 직원 화면에서 방 A 기록 입력, QR 만들기, 결과 보기와 CSV 내려받기
  - 한국어/영어
- 미완성 기능과 알려진 오류: 6절의 '알려진 문제'와 10절을 보세요.

## 2. 필요한 환경

- **운영체제:** 상관없음 (Windows 10 이상, macOS, Linux에서 확인)
- **관람객 휴대폰:**
  - 최근 2년 안의 iOS Safari, 안드로이드 Chrome, 삼성 인터넷
  - WebGL이 켜진 브라우저여야 함
  - 다크 모드에서도 금빛 글씨가 보이게 맞춤
- **빔 화면 PC:** 최신 Chrome 또는 Edge (전체 화면, F11)
- **내 컴퓨터에서 실행할 때:** Node.js 20 이상 (LTS 권장, https://nodejs.org). 설치하는 도구는 `package.json`에 적힌 wrangler 4.151.2, serve 14.2.6
- **화면:**
  - 휴대폰은 세로 화면 (390×844 기준으로 맞춤)
  - 빔 화면은 정사각형 1:1. 어떤 비율의 화면에 띄워도 가운데 정사각형으로 나오고 나머지는 검게 나옴. 최소 1080×1080 권장
- **스피커:** 필요 없음 (소리 없음, 휴대폰 진동만 씀)
- **인터넷:** 필요
  - 관람객 휴대폰과 빔 화면이 같은 서버(Cloudflare)를 통해 연결됨
  - 글꼴(고운바탕, IBM Plex Sans KR)은 Google Fonts에서 불러옴
  - 인터넷이 끊기면 체험은 이어지지만, 초롱이 빔 화면에 뜨지 않음. 기록은 휴대폰에 모아 두었다가 연결되면 다시 보냄
- **키넥트 등 센서:** 사용하지 않음. 관람객 휴대폰의 터치와 진동만 씀

## 4. 처음 실행하기

### 가장 빠른 방법 (설치 없음)

이미 올라가 있는 사이트를 엽니다.

| 용도 | 주소 |
| --- | --- |
| 관람객 휴대폰 (시험용 번호) | https://sugung-roomb.pages.dev/?id=0417 |
| 빔 화면 (위 휴대폰과 연결됨) | https://sugung-roomb.pages.dev/display |
| 시연용 (PC에서 휴대폰 틀, 번호 없이 시작) | https://sugung-roomb-demo.pages.dev |
| 시연용 빔 화면 (서버 없이 시험용 초롱이 계속 뜸) | https://sugung-roomb-demo.pages.dev/display |

### 내 컴퓨터에서 실행하기 (서버 포함)

1. ZIP을 새 폴더에 풉니다.
2. Node.js 20 이상을 설치합니다 (https://nodejs.org 의 LTS 버전).
3. 터미널(명령 프롬프트)을 열고 `02_작품코딩` 폴더로 이동합니다.
4. 도구 설치: `npm install` (1~2분)
5. 실행: `npm run dev`
6. 브라우저로 엽니다.
   - 휴대폰 화면: `http://localhost:8788/?id=0417` (PC 크롬이라면 F12 → Ctrl+Shift+M 으로 휴대폰 크기로 보기)
   - 빔 화면: `http://localhost:8788/display`
   - 직원 화면: `http://localhost:8788/staff` (PIN을 쓰려면 아래 참고)

휴대폰 화면에서 초롱을 날리면 같은 컴퓨터의 빔 화면에 떠오릅니다. 내 컴퓨터에서 저장한 기록은 실제 사이트와 섞이지 않습니다. 기록은 `main/.wrangler/` 폴더에만 남습니다.

직원 화면 PIN을 시험하려면 `.env.example`을 복사해 `main/.dev.vars`로 저장하고 `STAFF_PIN=` 뒤에 아무 4자리 이상 숫자를 적은 뒤 다시 실행하세요. 실제 PIN은 파일에 적지 않습니다.

`index.html`을 더블클릭해서 열면 동작하지 않습니다. 브라우저가 파일에서 직접 연 페이지의 모듈 스크립트를 막기 때문입니다. 반드시 위 방법으로 여세요.

### 실제 사이트에 올리기 (담당자만)

- 본 사이트: `npm run deploy`. 처음이면 Cloudflare 로그인을 묻습니다. 프로젝트 소유자 계정이나 그 계정의 API 토큰이 필요합니다.
- 시연용 사이트:
  ```
  npm run demo
  npx wrangler pages deploy demo --project-name sugung-roomb-demo --branch main
  ```

## 5. 관람객 체험 순서

1. **대기 화면 (휴대폰):** 방 A 출구에서 받은 A4의 QR을 찍으면 표지 '청사초롱, 꿈을 담다'가 열립니다. 표지에는 이 안내가 나옵니다. "방 A에서 담아온 것들이 초롱에 매달려 있어. 너무 무거워서 아직은 못 떠."
2. **관람객에게 알려줄 행동:**
   - 초롱 위·아래 색을 고릅니다. 초롱을 좌우로 밀어 돌려 볼 수 있습니다.
   - 초롱에 달린 꼬리표(최대 9개) 가운데 덜 중요한 것부터 하나씩 눌러 뗍니다. 마지막 하나가 남을 때까지 이어 갑니다.
   - '이걸로 정할게요'를 누르고 닉네임을 정한 뒤, 화면을 위로 쓸어 올려 초롱을 날립니다.
3. **행동을 인식하는 방식:**
   - 휴대폰 터치(누르기·좌우로 밀기·위로 쓸어 올리기)로 인식합니다. 센서는 쓰지 않습니다.
   - 날린 결과는 서버(`/api/participants/번호/roomB`)로 보냅니다.
4. **화면·소리의 반응:**
   - 꼬리표를 떼면 별가루로 바닷속에 잠기고, 토끼가 그 항목에 맞는 말을 자막으로 건넵니다.
   - 날리면 휴대폰이 진동하고 초롱이 하늘로 떠오릅니다.
   - 1.5초 안에 빔 화면에 그 사람의 초롱이 꼬리표 하나와 함께 떠오르고, 하단에 "○○의 청사초롱이 떠올랐어요"가 9초 동안 나옵니다.
   - 가까이 떠 있는 초롱은 7개이고, 넘으면 오래된 것부터 먼 하늘로 물러납니다.
5. **종료 화면 / 결과:**
   - 마무리 판에 '네가 남긴 것'(마지막 꼬리표)과 '이번 주에 해볼 일'(아주 작은 행동 하나)이 나옵니다.
   - '내 초롱 저장하기'로 이미지를 저장합니다.
   - 토끼가 "초롱이 큰 화면으로 날아갔어. 고개를 들어 찾아봐."라고 안내합니다.
6. **다음 관람객을 위한 자동 초기화 조건:**
   - 각자 자기 휴대폰으로 체험하므로 초기화할 공용 화면이 없습니다.
   - 현장 태블릿(`?kiosk=1`)은 마친 뒤 60초, 체험 중 아무 조작 없이 180초가 지나면 처음 화면으로 돌아갑니다. '다음 사람 시작하기' 버튼도 있습니다.

## 6. 운영자 조작

- **시작 / 일시정지 / 종료:**
  - 빔 화면은 PC 브라우저에서 `/display`를 열어 두기만 하면 됩니다. 일시정지는 없습니다.
  - 빔 화면은 연 뒤에 들어온 기록만 띄우므로 행사 중에는 새로고침하지 마세요.
- **전체 화면 전환:** 빔 화면에서 F11
- **처음 화면으로 초기화:**
  - 빔 화면: 새로고침하면 빈 하늘에서 다시 시작합니다.
  - 휴대폰: QR 주소를 다시 엽니다.
  - 태블릿: '다음 사람 시작하기'를 누릅니다.
- **센서가 없을 때 키보드·마우스 시연 방법:**
  - 센서는 원래 없습니다. PC에서는 https://sugung-roomb-demo.pages.dev 를 열면 휴대폰 틀 안에서 마우스로 시연됩니다.
  - 빔 화면 리허설: `/display?demo`는 6초마다, `/display?demo&fast`는 2.5초마다 시험용 초롱이 떠오릅니다.
- **소리 크기 조정:** 소리 없음
- **네트워크가 끊겼을 때:**
  - 휴대폰 체험은 계속됩니다. 기록은 휴대폰에 보관했다가 연결되면 자동으로 보냅니다.
  - 빔 화면은 연결이 돌아오면 1.5초 간격 확인으로 밀린 초롱을 띄웁니다.
- **참여 번호를 못 찾을 때:** 휴대폰 화면이 번호 입력 칸을 보여 줍니다. 직원 화면 '참여자' 탭에서 번호를 확인하세요.
- **프로그램이 멈췄을 때:** 해당 화면을 새로고침합니다. 빔 화면을 새로고침하면 지금 떠 있는 초롱은 사라지고 새 기록부터 다시 뜹니다.
- **알려진 문제:**
  - 아주 오래된 휴대폰이나 WebGL이 꺼진 브라우저에서는 3D 장면이 열리지 않습니다.
  - 아이폰은 웹에서 사진첩에 바로 저장할 수 없어 공유 창의 '이미지 저장'을 눌러야 합니다.

## 7. 동시 참여와 기록

- **동시에 체험할 수 있는 인원:**
  - 각자 자기 휴대폰을 쓰므로 인원 제한이 없습니다.
  - 빔 화면 하나에 여러 사람의 초롱이 차례로 뜹니다.
  - 동시 접속 시험은 미시험입니다. 빔 화면 연출은 2.5초 간격의 연속 입력까지 확인했습니다.
- **두 사람이 동시에 날리면:** 두 초롱이 서로 다른 칸에 떠오르고, 하단 안내는 차례로 바뀝니다.
- **중간에 들어온 사람이 시작하는 방법:** QR만 찍으면 언제든 처음부터 시작합니다. 앞사람의 진행과 상관없습니다.
- **앞사람의 선택이 다음 사람에게 남지 않게 하는 방법:**
  - 기록은 참여 번호별로 따로 저장됩니다.
  - 태블릿은 자동 초기화로 화면과 상태를 비웁니다.
- **저장하는 정보:** 서버(Cloudflare KV 저장소 `ROOMB`)에 참여 번호별로 저장합니다.
  - 방 A에서 고른 항목
  - 뗀 순서와 되돌린 기록
  - 마지막 남긴 항목
  - 초롱 색
  - 닉네임 (6글자 이내)
  - 시작·종료 시각
  - 이름·전화번호 같은 개인정보는 받지 않습니다.
- **공통 화면에 표시하는 것:** 닉네임(없으면 참여 번호)과 마지막 남긴 꼬리표 하나만 보여 줍니다.
- **가상 데이터로 시험하는 방법:**
  - 시험용 번호 `0417`, `0102`는 서버 기록 없이도 샘플 항목 9개로 시작합니다 (`index.html`의 `SAMPLE_DB`).
  - 실제 관람객 기록은 이 ZIP에 들어 있지 않습니다.
- **서버 API:**

| 요청 | 하는 일 | 실패 시 |
| --- | --- | --- |
| `GET /api/health` | 서버 연결 확인 | 서버 없이 샘플 번호로만 동작 |
| `GET /api/participants/{번호}` | 방 A 항목 불러오기 → `{ id, items: [...] }` | 404면 번호 다시 입력 |
| `POST /api/participants/{번호}/roomB` | 방 B 결과 저장, 빔 화면 목록에 추가 | 휴대폰에 보관 후 재전송 |
| `POST /api/participants/{번호}/roomB/color` | 초롱 색 바꾸기 | 무시 |
| `GET /api/feed?after=시각` | 빔 화면이 새 초롱 목록을 가져감 (최근 80개) | 다음 확인 때 다시 |
| 직원용 API | 방 A 기록 입력·참여자·결과 목록 | PIN(`STAFF_PIN`)이 맞아야 동작 |

비밀값은 `STAFF_PIN` 하나이며, 이름만 `.env.example`에 적었습니다.
