# 용왕님의 보물의 방-2조

별주부전의 용궁을 배경으로 한 스탠바이미용 터치형 미디어아트입니다. 관람객이 안개를 걷고 보물의 방에 들어가면 여섯 봉인이 생깁니다. 세 상자 속 일상 장면에서 나를 닮은 행동을 선택해 빛을 얻고, 빛을 봉인으로 옮겨 방을 탈출합니다. 마지막에는 선택한 행동에 연결된 여섯 보물과 설명을 결과지로 확인합니다.

- 체험 주소: [수궁야행](https://sugung-treasure-room.gardenloon1.chatgpt.site/)
- 작성 기준: 2026년 10월 20일
- 기본 언어: 한국어 / 오른쪽 위 버튼으로 영어 전환
- 입력 장치: 터치스크린 또는 마우스
- 청취 장치: 헤드폰 권장
- 카메라·마이크·외부 센서: 사용하지 않음

## 1. 설치 및 실행

### 필요한 환경과 버전

| 항목 | 요구 사항 |
| --- | --- |
| Node.js | **22.12.0 이상**, 전시용 설치는 Node.js 22 LTS의 22.12 이상 권장 (`.nvmrc`: `22`) |
| npm | Node.js에 포함된 npm 사용, `package-lock.json` 기준 설치 |
| 브라우저 | Google Chrome 권장. 실제 스탠바이미의 내장 브라우저는 별도 기기 검증 필요 |
| 주요 구성 | React 19.3.1, Vite 8.3.4 — 재현 가능한 설치 버전은 `package-lock.json` 기준 |
| 서버 | 별도 데이터베이스나 애플리케이션 백엔드 불필요. 정적 웹 서버 필요 |

### 설치 없이 확인하기

위 체험 주소를 브라우저에서 엽니다. 이 방법은 인터넷 연결이 필요하며 Node.js 설치는 필요하지 않습니다.

### 소스를 받아 실행하기

이 README와 `package.json`이 있는 폴더에서 터미널을 엽니다.

```sh
node --version
npm --version
npm ci
npm run dev -- --port 5173 --strictPort
```

브라우저에서 `http://127.0.0.1:5173/`에 접속합니다. 서버를 실행한 터미널을 유지해야 하며, 종료는 `Ctrl+C`입니다.

`npm ci`를 실행하려면 `package.json`과 `package-lock.json`이 함께 있어야 합니다. 프로젝트를 전달할 때 `src/`, `public/`, `index.html`, 설정 파일도 함께 전달합니다.

### 전시용 빌드 확인

```sh
npm run build
npm run preview -- --port 4173 --strictPort
```

`http://127.0.0.1:4173/`에서 확인합니다. 빌드 결과는 `dist/`에 생성됩니다. Vite preview는 로컬 확인용이며, 전시 운영은 공개 배포 주소 또는 `dist/`를 제공하는 정적 웹 서버를 사용합니다. `index.html`을 더블클릭하는 `file://` 방식은 지원하지 않습니다.

스탠바이미와 실행용 PC가 다른 기기라면 PC의 `127.0.0.1` 주소로 접속할 수 없습니다. 공개 체험 주소를 사용하거나, 같은 네트워크의 PC를 다음과 같이 실행해 PC의 LAN IP로 접속합니다.

```sh
npm run preview -- --host 0.0.0.0 --port 4173 --strictPort
```

예: `http://192.168.0.10:4173/` — 실제 PC IP를 사용하고 방화벽에서 해당 포트 접근을 허용해야 합니다.

## 2. 인터넷 연결 여부

| 사용 방식 | 인터넷 필요 여부 |
| --- | --- |
| 최초 Node.js·패키지 설치 | 필요. 이미 설치된 실행 환경을 전달한 경우 제외 |
| 공개 체험 주소 접속 | 필요 |
| 설치·빌드 완료 후 로컬 서버에서 체험 | 핵심 체험은 인터넷 없이 실행 가능. 이미지·음원은 프로젝트에 포함 |
| Google Fonts 웹폰트 | 인터넷 필요. 연결이 없으면 시스템 대체 글꼴로 표시되어 줄바꿈·모양이 달라질 수 있음 |
| 결과지 QR 생성 및 PNG 저장 | 브라우저 안에서 처리하므로 그 작업 자체는 인터넷 불필요 |
| 휴대전화에서 QR 결과 링크 열기 | QR에 담긴 웹 주소에 접근할 수 있어야 함. 공개 주소는 인터넷 필요 |

현재 오프라인 설치형 PWA나 서비스 워커 캐시 기능은 구현되어 있지 않습니다. 온라인 페이지를 한 번 열어 두었다는 이유만으로 이후 오프라인 동작을 보장하지 않습니다.

**전시에서 QR 저장을 제공하려면 공개 체험 주소로 실행하는 것을 권장합니다.** QR은 현재 접속 주소를 사용합니다. 로컬 `127.0.0.1`에서 만든 QR은 관람객 휴대전화로 열 수 없으며, LAN 주소도 같은 네트워크에서만 접근할 수 있습니다.

## 3. 화면 해상도와 비율

- 기준 화면: **1920 × 1080, 가로 16:9**.
- 보조 확인 크기: **1536 × 864, 가로 16:9**.
- 스탠바이미는 가로 방향, 브라우저 배율 **100%**, 전체화면 사용을 권장합니다.
- 화면 크기에 맞춰 배경이 채워지며, 화면 비율이 달라지면 배경 가장자리가 일부 잘릴 수 있습니다.
- 세로 화면은 주 체험용 권장 규격이 아닙니다. 휴대전화에서는 QR로 연 결과지 열람·저장을 지원합니다.
- 전체화면 진입은 화면의 전체화면 버튼 또는 브라우저 기능을 사용합니다. 기기에 따라 지원 여부가 다를 수 있습니다.

## 4. 체험 흐름과 운영 방법

1. **안개 걷기**: 손가락으로 화면을 드래그합니다. ‘안개 한 번에 걷기’ 버튼도 사용할 수 있습니다.
2. **문 열기**: 드러난 문을 터치하면 문 안으로 들어갑니다.
3. **봉인 발생**: 문 닫힘 효과음·화면 흔들림과 함께 여섯 봉인이 나타납니다. 안내를 읽고 ‘보물을 찾아 탈출하기’를 누릅니다.
4. **상자 선택**: 세 상자 중 하나를 고르고, 안내를 읽은 뒤 ‘이야기 속으로 들어가기’를 누릅니다.
5. **미션 선택**: 상자마다 이어지는 두 장면이 있으며, 각 장면에서 다섯 해양생물 중 나를 닮은 행동을 하나 선택합니다.
6. **봉인 해제**: 상자 하나를 마치면 방으로 돌아옵니다. 얻은 빛 두 개를 문 위 봉인으로 드래그합니다. 빛을 누른 뒤 봉인을 누르는 조작도 가능합니다. 완료한 상자는 열린 상태로 남습니다.
7. **탈출**: 세 상자의 여섯 선택과 여섯 봉인 해제를 마치면 마지막 안개를 걷고 열린 문을 통해 탈출합니다.
8. **결과 확인**: 여섯 보물의 이름·설명·내가 선택한 행동을 확인하고, QR로 휴대전화에서 열거나 PNG로 저장합니다.

BGM·물속 환경음·효과음이 함께 재생됩니다. 브라우저의 자동 재생 제한으로 첫 화면에서 소리가 나지 않으면 화면을 터치하고 소리 버튼을 확인합니다. 헤드폰 연결과 기기 음량도 별도로 확인합니다.

진행 중 90초간 입력이 없으면 안내가 나오며, 이후 15초간 응답이 없으면 초기화됩니다. 입장 안내 등 일부 대기 상태에서는 초기화를 잠시 멈춥니다. 결과 화면의 ‘다음 관람객 시작’으로 새 체험을 시작할 수 있습니다. 새로고침하면 현재 진행은 사라집니다.

| 움직임·성능 | 저사양 기기나 브라우저의 동작 줄이기 설정에서는 연출이 축소되거나 부드러움이 달라질 수 있음 |
| 자료 이용 허락 | 제공 이미지·음원 중 출처와 이용 허락이 미확인인 항목이 있음. 위 출처 표 보완 필요 |

현재 문 입장·봉인 효과음·미션 전환 등 최근 수정 사항은 PC Chrome의 관련 자동 브라우저 검사 6개를 통과했습니다. 과거 보고된 마지막 안개 미표시·글자 겹침 문제는 수정 대상에 반영되었으나, 모든 실제 기기에서 동일하게 검증했다는 의미는 아닙니다.

결과지는 자기 탐색을 위한 체험 결과이며, 성격·능력을 진단하거나 점수로 평가하는 검사가 아닙니다. 이름·연락처를 수집하지 않고, 선택 결과는 QR 링크의 코드에 담습니다. 링크를 가진 사람은 같은 결과를 열 수 있으며, 서버에 관람객별 결과를 별도 저장하는 기능은 없습니다.

## 7. 문제가 생겼을 때

1. 소리가 안 나면 헤드폰 연결·기기 음량·화면의 소리 버튼을 확인하고 화면을 한 번 터치합니다.
2. 화면이 작거나 잘리면 가로 방향·브라우저 배율 100%·전체화면 여부를 확인합니다.
3. 이미지나 음원이 안 뜨면 온라인 연결 또는 로컬 서버 실행 상태를 확인합니다. `file://`로 실행하지 않습니다.
4. 진행이 멈추면 새로고침해 재시작합니다. 현재 관람객의 진행은 초기화됩니다.
5. QR이 안 열리면 QR에 담긴 주소가 공개 주소인지 확인하고 ‘내 결과지 열기’를 사용합니다.
