# 마음의 물결 — 인터랙티브 미디어아트 (수정 버전)

## 실행
압축 해제 후 이 폴더에서 `python3 -m http.server 8000` 실행, Chrome에서 http://localhost:8000 접속.

## 조작
- 시작 버튼: 오프닝 영상 재생
- 1번: 물방울에 마우스를 1초 머무르면 노란빛 선택
- 2번: 세로로 내리는 단어를 **클릭**하면 황금빛으로 변해 입자화
- 하단 물웅덩이는 받은 단어가 쌓일수록 금빛으로 물듦. 숫자 카운터는 표시하지 않음
- 3번: 마우스 좌우 이동으로 물결 기울이기 (현재 실시간 시안, 추후 영상 교체 가능)
- 키보드 1: 처음으로 / 2,3,4: 각 장면 테스트

## 포함 영상
opening.mp4, selection_bg.mp4, rain_bg.mp4, ending.mp4

## 주의
브라우저에서 영상 재생 및 전 장면 통합 실사용 테스트는 별도로 필요합니다.

## v3 변경
- 1번: 비눗방울처럼 투명한 막, 무지개 굴절, 시간에 따라 움직이는 반사광/반짝임
- 2번: 클릭하지 않은 단어는 물웅덩이 표면에 닿아 물보라와 파문으로 사라짐
- 클릭한 단어는 노란빛 입자로 변하고, 물웅덩이에 금빛이 누적됨

## 이번 업데이트
- 1번 인터랙션: 참조한 4번 시안처럼 중심이 투명하고 가장자리 무지개 간섭색이 보이는 애니메이션 비눗방울.
- 표면 반사광, 굴절 띠, 반짝이는 광점이 계속 움직임.
