## 1. 체험 화면 (휴대폰 · `index.html`)

### 표지 · 시작
- 글꼴이 깨져 보이던 현상 수정
- '이 초롱으로 시작하기' 버튼을 화면 맨 아래로 옮김
- 로딩 시간을 고려해, 초롱 색 고르기 화면이 열린 뒤 3초가 지나야 시작 버튼을 누를 수 있음
- 휴대폰 다크 모드에서 금빛 글씨가 어둡게 보이던 문제 → 샴페인 골드 자개빛으로 canvas 에 직접 그림 (제목·라벨·이름표 등)

### 초롱 색 고르기
- 색 팔레트 위치를 위로 올림
- 다크 모드에서 노랑 칸이 어둡게 보이던 문제 수정
- 색을 바꾸면 새 색이 왼쪽부터 스르륵 물들고, 이전 색은 오른쪽으로 빠져나감
- 빠져나가는 효과: 작은·중간·큰 빛 알갱이 + 가끔 반짝이는 십자 별빛 4개 (크기 제각각)
  - 색칠이 끝나 보이는 순간에 초롱 오른쪽 끝에서만 생겨남
  - 사라질 때 거뭇한 얼룩이 생기지 않고, 다크 모드에서도 보이게 그림
- 초롱 뒤 빛 번짐을 테두리 없는 부드러운 halo 로 바꿈 (색 바꿀 때 두 배로 밝아지지 않음)
- 3D 미리보기를 화면 전체를 덮는 불투명 그림으로 바꿈 → 삼성 인터넷 다크 모드에서 빛에 둥근 테두리가 생기던 문제 해결

### 꼬리표(네임택) · 초롱
- 꼬리표 항목을 일상 돌보기 15가지로 교체 (`catalog.js`)
  - 몸 돌보기: 양치하기, 샤워하기, 물 마시기, 밥 챙겨 먹기, 스트레칭하기, 일찍 눕기
  - 공간 돌보기: 창문 열기, 이불 정리, 옷 갈아입기, 설거지하기, 화분 돌보기
  - 마음 돌보기: 산책하기, 햇볕 쬐기, 안부 전하기, 노래 듣기
- 영어 이름, '이번 주에 해볼 일'(아주 작은 행동), 그 영어판도 새 항목에 맞춰 교체
- 꼬리표를 뗄 때 뜨는 자막이 뗀 항목에 맞는 토끼의 말로 바뀜 (예: "스트레칭은 바닷속에 맡겨 둘게. 몸이 뻐근할 때 다시 꺼내 보자.")
- 초롱에 다는 꼬리표는 최대 9개 (방 A에서 더 많이 담아 와도 앞의 9개만)
- 초롱과 꼬리표를 잇는 끈을 꼬아 만든 동아줄 모양으로 바꿈
- 초롱 아래 술에 실결과 금사 질감을 넣음 (모양은 그대로)
- 마지막 '하나 되돌리기'가 작동하지 않던 문제 수정

### 이름 정하기 ('어떤 이름으로 불리고 싶어?')
- 창을 화면 맨 위에, 3:4 비율로, 네 귀퉁이 무늬를 넣음
- 키보드가 올라와도 창이 다 보이게 맞춤, 창 밖을 누르면 키보드만 내려감
- 제목의 자개빛은 거의 티 나지 않게 아주 희미하게
- '이 이름으로 띄울게요': 이름 입력 전에는 단색 금빛, 입력하면 흰 글씨 + 금빛 번짐 (다크 모드에서도 보이게 canvas)
- '랜덤 닉네임 생성하기': 처음부터 흰빛에 가깝게, 글씨 조금 작게
- '돌아가기': 창 밖 화면 맨 아래로 옮김 (키보드가 올라오면 키보드 바로 위), 밑줄 없음, 랜덤 닉네임과 같은 색
- 닉네임 입력칸: 다크 모드 화면에서 고른 색(남색 바탕 · 어두운 안쪽 선 · 입력 중 어두운 금빛 바깥 테)으로, 라이트·다크 모드 모두 같게
- '차차'처럼 한글을 이어 칠 때 미리보기가 한 글자만 보이던 문제 수정
- 이름 창이 열려 있는 동안 뒤의 '이걸로 정할게요'·'하나 되돌리기'는 숨김

### 날리기 · 마무리
- 위로 미는 화살표: 기둥 양쪽 선이 아래로 갈수록 가늘고 흐려지며 사라짐, 전체적으로 더 불투명하게
- 마무리 판의 '초롱 색 바꾸기'를 없애고 '내 초롱 저장하기' 하나만 남김 (글자 기준 위아래 한가운데)
- 마무리 판 '네가 남긴 것'·'이번 주에 해볼 일' 제목은 그라데이션 없는 단색 금빛
- 내 초롱 저장하기 (팀원 추가 기능)
  - 저장 이미지에서 초롱 위 고리·아래 술이 잘리던 문제 수정
  - 안드로이드는 공유 창 없이 갤러리(다운로드 앨범)에 바로 저장, 아이폰은 공유 창의 '이미지 저장' 사용 (웹에서 사진첩에 직접 넣는 방법 없음)

## 2. 빔 화면 (프로젝터 · `display.html`)

- 어떤 화면비에서도 정사각형으로 출력 (나머지는 검게)
- 가까이 떠 있는 초롱 7개는 2·3·2 세 줄 벌집 모양 칸에 놓여 거의 겹치지 않음 (바다 위까지 내려옴)
- 8번째 초롱부터는 별이 되지 않고, 왼쪽부터 먼 하늘에 흐릿하게 떠 있음 (네임택 없음, 크기·선명도·밝기 제각각)
- 멀어지는 움직임: 천천히 출발해 빨라지고, 길게 스르르 멈춤 (15초) · 자리 잡을 때 덜컹하지 않음
- 초롱 빛 번짐이 진한 원으로 보이던 실수 수정
- 꼬리표 끈을 꼬아 만든 동아줄로 (굵기 = 술 아랫부분 너비의 1/3, 술 아래 살짝 떨어져 시작)
- 시험 모드(`?demo`)도 새 항목으로
