선택한 말이 마음의 방향을 만듭니다

왼쪽은 발전하고자 하는 삶, 오른쪽은 안정적인 삶입니다. 기반·보상·생활 균형은 안정, 자율·배움·창조·영향력 확장은 발전으로 분류합니다.

단어 한 번 선택 = 해당 방향 1점

인터랙티브 1의 7개 선택 점수와 인터랙티브 2에서 잡은 단어 점수를 합산합니다. 같은 단어를 여러 번 잡으면 그만큼 점수가 쌓입니다. 최대 7+15=22점입니다.

발전 점수가 높으면 공이 왼쪽으로, 안정 점수가 높으면 오른쪽으로 움직이는 영상을 재생합니다. 동점이면 마지막으로 잡은 단어의 방향을 따릅니다. 잡은 단어가 없으면 마지막 질문에서 고른 단어를 따릅니다.

질문왼쪽 · 발전 +1오른쪽 · 안정 +1

기존 배경과 앞뒤 영상은 유지됩니다. 마음의 기울기는 균형 → 흔들림 → 점수에 따른 방향 결정 → 해당 세계 접근 순서로 이어집니다.
